# Candela

Interactive revision through prediction, experimentation, explanation and exam practice.

## Prototype

The first prototype focuses on GCSE Physics and currently includes:

- Forces / stopping distance
- Predict → Experiment → Explain → Exam flow
- Interactive speed and reaction-time controls
- Local progress tracking with `localStorage`
- Mobile-friendly layout

The project is intentionally broader than physics and may later expand into other GCSE subjects.
